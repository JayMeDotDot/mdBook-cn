# mdBook-cn

[![语言](https://img.shields.io/badge/语言-中文-green.svg)](https://github.com/JayMeDotDot/mdBook-cn)
[![上游版本](https://img.shields.io/crates/v/mdbook.svg?label=上游版本)](https://crates.io/crates/mdbook)
[![LICENSE](https://img.shields.io/github/license/jaymedotdot/mdBook-cn.svg?label=许可协议)](LICENSE)

mdBook 是一个用于从 Markdown 文件创建现代在线书籍的工具。

查看 **[用户指南][User Guide]**，了解功能列表以及安装和使用信息。
该用户指南同时也用作演示，展示一本书是什么样子。

如果你有兴趣为 mdBook 的开发做出贡献，请查看 [贡献指南][contribution guide]。
