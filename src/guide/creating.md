# 创建一本书

安装好 `mdbook` 命令行工具之后，你就可以用它来创建和渲染一本书了。

## 初始化一本书

`mdbook init` 命令会创建一个新目录，其中包含一本空书，供你开始使用。把你想创建的目录名传给它即可：

```sh
mdbook init my-first-book
```

在生成这本书之前，它会先问你几个问题。回答完这些问题后，你可以把当前目录切换到这本新书中：

```sh
cd my-first-book
```

渲染一本书有几种方式，其中最简单的方法之一是使用 `serve` 命令，它会构建你的书并启动一个本地 web 服务器：

```sh
mdbook serve --open
```

`--open` 选项会打开你的默认 web 浏览器来查看这本新书。即使在你编辑书的内容时，也可以让服务器一直运行，`mdbook` 会自动重新构建输出 *并* 自动刷新你的 web 浏览器。

欲了解其他 `mdbook` 命令和命令行选项的更多信息，请查阅 [CLI 指南](../cli/index.html)。

## 一本书的构成

一本书由若干文件组成，这些文件定义了书的设置和布局。

### `book.toml`

在你的书的根目录下，有一个 `book.toml` 文件，其中包含描述如何构建你的书的设置。它使用 [TOML 标记语言](https://toml.io/)编写。默认设置通常足以让你开始使用。当你有兴趣探索 mdBook 提供的更多特性和选项时，请查阅 [配置章节](../format/configuration/index.html) 了解更多细节。

一个非常基础的 `book.toml` 可以简单到像这样：

```toml
[book]
title = "我的第一本书"
```

### `SUMMARY.md`

一本书的下一个主要部分是位于 `src/SUMMARY.md` 的 summary 文件。这个文件包含书中所有章节的列表。在一个章节可以被查看之前，必须先把它添加到这个列表中。

下面是一个包含几个章节的基础 summary 文件：

```md
# Summary

[简介](README.md)

- [我的第一个章节](my-first-chapter.md)
- [嵌套的例子](nested/README.md)
    - [子章节](nested/sub-chapter.md)
```

试着在你的编辑器中打开 `src/SUMMARY.md` 并添加几个章节。如果某些章节文件不存在，`mdbook` 会自动为你创建它们。

欲了解 summary 文件其他格式选项的更多细节，请查阅 [Summary 章节](../format/summary.md)。

### 源文件

你这本书的内容全部放在 `src` 目录中。每个章节是一个单独的 Markdown 文件。通常，每个章节都以一个带有章节标题的一级标题开头。

```md
# 我的第一个章节

在此处输入你的内容。
```

文件的具体布局由你决定。文件的组织方式会与生成的 HTML 文件相对应，因此请记住，文件布局是每个章节 URL 的一部分。

在 `mdbook serve` 命令运行期间，你可以打开任意章节文件并开始编辑它们。每当你保存文件时，`mdbook` 都会重新构建这本书并刷新你的 web 浏览器。

欲了解格式化章节内容的更多信息，请查阅 [Markdown 章节](../format/markdown.md)。

`src` 目录中的所有其他文件都会被包含在输出中。因此，如果你有图片或其他静态文件，只需把它们放在 `src` 目录中的某个位置即可。

## 发布一本书

写完你的书之后，你可能想把它托管在某个地方供他人查看。第一步是构建这本书的输出。这可以在 `book.toml` 文件所在的目录中使用 `mdbook build` 命令来完成：

```sh
mdbook build
```

这会生成一个名为 `book` 的目录，其中包含你这本书的 HTML 内容。然后你可以把这个目录放到任何 web 服务器上来托管它。

欲了解发布和部署的更多信息，请查阅 [持续集成章节](../continuous-integration.md)。
