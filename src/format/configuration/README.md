# 配置

本节详细介绍 ***book.toml*** 中可用的配置选项：

- **[通用][General]** 配置，包括 `book`、`rust`、`build` 小节
- **[预处理器][Preprocessor]** 配置，用于默认及自定义的书籍预处理器
- **[渲染器][Renderer]** 配置，用于 HTML、Markdown 及自定义渲染器
- **[环境变量][Environment Variable]** 配置，用于在环境中覆盖配置选项

[General]: general.md
[Preprocessor]: preprocessors.md
[Renderer]: renderers.md
[Environment Variable]: environment-variables.md
