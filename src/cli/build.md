# build 命令

build 命令用于渲染你的书籍：

```bash
mdbook build
```

它会尝试解析你的 `SUMMARY.md` 文件以了解书籍的结构，并获取相应的文件。注意，这一过程还会创建 `SUMMARY.md` 中提到但尚未存在的文件。

为方便起见，渲染输出会保持与源文件相同的目录结构。因此，大型书籍在渲染后仍能保持原有的结构。

#### 指定目录

`build` 命令可以接受一个目录作为参数，将其用作书籍的根目录，而不是使用当前工作目录。

```bash
mdbook build path/to/book
```

#### `--open`

使用 `--open`（`-o`）标志时，mdbook 会在构建完成后用你的默认网页浏览器打开渲染好的书籍。

#### `--dest-dir`

`--dest-dir`（`-d`）选项允许你更改书籍的输出目录。相对路径将相对于当前目录进行解析。如果未指定，则默认使用 `book.toml` 中 `build.build-dir` 键的值，或者为 `./book`。

-------------------

***注意：*** *build 命令会将源目录中的所有文件（不包括扩展名为 `.md` 的文件）复制到构建目录中。*
