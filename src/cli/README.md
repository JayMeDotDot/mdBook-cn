# 命令行工具

`mdbook` 命令行工具用于创建和构建书籍。在[安装](../guide/installation.md)好 `mdbook` 之后，你可以在终端中运行 `mdbook help` 命令来查看可用的命令。

以下各节将详细介绍各个可用命令。

* [`mdbook init <directory>`](init.md) --- 创建一本新书，包含最少的样板文件，方便你上手。
* [`mdbook build`](build.md) --- 渲染书籍。
* [`mdbook watch`](watch.md) --- 每当源文件发生变动时，自动重新构建书籍。
* [`mdbook serve`](serve.md) --- 运行一个 web 服务器来预览书籍，并在内容变动时重新构建。
* [`mdbook test`](test.md) --- 测试 Rust 代码示例。
* [`mdbook clean`](clean.md) --- 删除渲染生成的输出。
* [`mdbook completions`](completions.md) --- 提供 shell 自动补全支持。
